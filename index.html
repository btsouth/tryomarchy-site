why try it here

Keep your Windows setup

No new partitions or bootloader. Setup can enable Windows Hypervisor Platform and ask for a restart. Use the built-in uninstall option when you are finished.

It's the real thing

This is the real Omarchy desktop, running on your machine. Every theme, every screensaver, the whole experience. Not a slideshow of someone else's screen.

Use your graphics card

GPU acceleration makes the desktop and video responsive on compatible drivers. A CPU rendering option is available when a graphics driver needs a fallback.

It behaves like an app

It runs in a normal window, not a VM console. The Windows key drives Omarchy while the window is focused and Windows everywhere else. Copy text, images and files between desktops, or drop files into Omarchy without a transfer window taking over.

in the latest preview

Use your Windows camera and microphone in Linux apps, drag files into an open folder or Downloads, and keep working while larger transfers run. Audio playback, shared folders and clipboard integration connect the two desktops.

Back up your installation, take a snapshot before making changes, grow its disk or move it to another drive. Signed launcher updates and recovery tools help keep your files safe. Read the release notes for current features and limits.

how it works

Under the hood it's a lightweight virtual machine, using virtualization that Windows already includes (the same one WSL2 uses). A ready-made Omarchy system boots inside a normal app window. Your Windows apps keep working like always; the Linux desktop just lives in its own window.

Want the technical details? They're all written up in FINDINGS.md.

try it today

Download the TryOmarchy.exe launcher and open it. The first run sets everything up by itself: Windows asks permission to switch on the virtualization it already includes and restarts once, then the app pulls the graphics runtime and a multi-gigabyte Omarchy image. Everything it needs comes with it, QEMU included - there's nothing else to install. After that, every launch goes straight to the desktop. No commands, no sign-in screens, no console text.

questions

Is this official?

Try Omarchy for Windows is maintained in the Omarchy GitHub organization. It is currently a preview, with a stable v1 still in progress. See the project on GitHub for the latest release and known limitations. Learn about Omarchy at omarchy.org.

Will it mess up my PC?

It does not repartition your drive or replace your bootloader. Setup may enable Windows Hypervisor Platform, request a restart and add app shortcuts. Linux data lives in the installation folder. Use Settings to back up your files or uninstall the app; shared folders remain your Windows files.

Which versions of Windows work?

Try Omarchy targets 64-bit Windows 10 and 11, Home or Pro, with hardware virtualization enabled. Physical testing currently centers on an AMD Windows 11 laptop. See the compatibility guide for tested configurations and remaining limitations.

What kind of PC do I need?

You need an x86_64 processor with hardware virtualization enabled, enough free space for the downloaded image and a growing Linux disk, and memory available for both Windows and Omarchy. Graphics performance depends on your GPU and driver. Check the compatibility guide before downloading.

Can I install Linux apps?

Yes. This is a full Arch Linux environment, so pacman, yay, VS Code, and other graphical Linux apps work normally. See the compatibility guide for current VM limits.

How do I actually install Omarchy?

That's the idea: try it here first. When you're ready for the real thing, Omarchy installs straight onto your machine. Head to omarchy.org.
