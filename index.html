A few good questions

Before you
jump in.

Does this replace macOS or Windows?

No. Omarchy runs in a virtual machine inside an app. There is no repartitioning or dual boot. Windows setup may enable its virtualization feature and ask for a restart.

Is this the full Omarchy desktop?

Yes. You can explore the desktop, themes, and Linux apps. Host integration and hardware support differ between the Mac and Windows versions. Performance depends on your computer and the app. Video decoding on Mac is currently CPU-only.

Will my Linux files stay between sessions?

Windows keeps your Linux files in its installation folder. On Mac, check the app's storage mode: persistent environments keep your changes, while disposable environments do not.

What if I’m ready to install Omarchy directly?

Visit omarchy.org for installation options and hardware guidance.
